# Тетрадката

Платформа за учене и упражнения за 6. клас. Статична (GitHub Pages), без вход; прогресът се пази в браузъра (`tetradka.v1`), корицата – в `tetradka.cover`.

- `index.html` – приложението: табло „Днес“, предмети и теми с нива на усвояване, интерактивни уроци, упражнения с преговор на грешките, дневник, печати, отчет, корица.
- `platform.json` – предмети, учебници, теми (с `skills` префикси и по желание `lesson`), разписание по дни, предстоящи изпитвания.
- `lessons/*.json` – уроци от блокове: hook, goals, text, image, check, map, timeline, order, cards, debate, links, summary + `quiz` (задачи като в сесиите).
- `sessions.json` – упражнения. Нови се добавят в края; съществуващите не се променят (прогресът е вързан за id).
- `plan.json` – текущи теми и слаби места; `feedback.json` – бележки от проверката, показват се на таблото.

Задачи: `mc`, `num`, `short`, `open` (самооценка 0–2 по рубрика). Всяка задача има `skill`, напр. `ist.krum.voini`, `mat.stepeni.znak`.
