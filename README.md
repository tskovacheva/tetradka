# Тетрадката

Упражнения за самоподготовка по БЕЛ и математика, 6. клас. Статична страница (GitHub Pages), без вход.

- `index.html` – приложението. Резултатите се пазят в localStorage на устройството (`tetradka.v1`), с отчет за родителя и резервно копие.
- `sessions.json` – масив от сесии. Нови сесии се добавят в края на масива; съществуващите не се променят (резултатите са вързани за `id` на сесия и задача).
- `plan.json` – текущи теми и слаби места; по него се генерират новите сесии.

Формат на задача: `mc` (options, answer = индекс), `num` (answer, tol, unit), `short` (accept[]), `open` (model, rubric за 0–2 т.). Всяка задача има `skill` (напр. `bel.mest.koi-kogo`, `mat.krug.lice`).
